| 区域 | V1 | V1.1 |

| 本地模型 | 与在线来源并列 | 底部文字入口，按需展开；保留真实签名与兼容性检查 |

| 全屏 | 常规预览控制 | 页面级全屏回退、独立退出按钮；桌面及手机尺寸 Chromium 的实际淡出、恢复和退出已补测 |
| 过渡 | 基础状态变化 | 短暂淡入、菜单、按钮反馈、加载状态；尊重减少动画偏好 |

## 实际修复

- 为预览 Canvas 增加等比例显示，避免纵向媒体在横向容器中拉伸。
- 极小分类图片的文字行高按画布高度调整，避免底部重叠。
- 修正模型返回首页后的旧初始化文案、动态错误的中英文切换及本地模型的来源显示。
- 修复高分辨率图片独立取整后产生的裁切越界；JSON 同时记录实际 `scaleX` / `scaleY`。
- 修复摄像头授权、文件解码和视频播放跨后台或模式切换的异步状态边界。

历史记录中的 opacity `1` 疑点已补测：同一应用指纹在桌面及 375×650 Chromium 视口真实视频推理时降至 `0`，交互后恢复至 `1`；见 [验收证据](ACCEPTANCE.md)。这仅确认云端 UI，不代表 iPhone 动画已通过。原生全屏、真实摄像头、iOS 安全区域和主屏幕安装的设备行为仍须真机验证，见 [PWA 验证报告](PWA_VALIDATION.md)。

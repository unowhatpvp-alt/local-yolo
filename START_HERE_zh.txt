Local YOLO — Minimal V1.1 候选版
更新日期：2026-10-21（America/New_York）

这是浏览器本地 YOLO 推理工具，通过静态站点运行，无须 Python 推理服务器。
第一版本优先简化界面、改善交互并保持稳定；不扩展 Studio 或训练功能。

使用：
1. 安装 Node.js 22.12 或以上版本，在仓库目录执行 npm ci。
2. 执行 npm run dev，打开终端显示的 /local-yolo/ 地址。
3. 选择任务、大小并启动模型。初始化后默认进入摄像头；也可选择上传图片或视频。
4. 相机选项包含设备、镜像和倍率；右上结果菜单包含 PNG 和 JSON 导出。
5. npm run build 生成 dist；npm run preview 可预览构建产物。

在线模型：YOLO26 的检测、分割、姿态、分类、旋转框 × N/S/M/L/X，共25个。
模型有固定来源、版本、字节数和 SHA-256；本地 ONNX 只接受受支持的 YOLO 格式。
首次使用需要下载，已缓存模型可再次读取；缓存可能被浏览器清理。
图片、视频和结果只在设备上处理，应用没有媒体上传接口。
